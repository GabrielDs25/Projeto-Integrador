# Índice de evidências

Adicionar ao longo do projeto:
- captura ou link da CI verde;
- resultados experimentais em CSV/JSON e comando para reproduzi-los;
- logs com data e hora;
- pelo menos três casos de falha e análise da causa;
- vídeo de demonstração de 3 a 5 minutos;
- capturas de tela úteis.

Não adicionar dados pessoais reais, senhas ou chaves de API.
